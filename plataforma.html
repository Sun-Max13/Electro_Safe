Manuales y documentación

La documentación del grupo ya está incluida. Lo que cargues aquí se suma como fuente del asistente. Sube .txt/.md o pega texto; los PDF se guardan pero el asistente no los lee.

Documentos del repositorio

Se abren dentro de esta misma página.

Reportes

Genera un reporte de cualquier módulo para imprimir o guardar como PDF, o descárgalo en CSV para abrirlo en Excel.

Base de datos

Tablas del sistema y cuántos registros tiene cada una. Los datos se guardan en este navegador. Exporta un script SQL para llevarlos a un motor como MySQL, PostgreSQL o SQLite.

El script incluye la estructura y los registros. Las fotografías y los PDF no se exportan en el SQL; para respaldarlos usa Exportar datos (JSON) en el Dashboard.

Asistente IA
